DP is an Optimisation technique used when a problem has 
1- overlapping subproblems 
2- optimal  sub structure 
    we use  optimal results of subproblems to achieve optimal solution of the bigger Problem      
- In DP we find the optimal solution of bigger problems using the optimal solution of small problems
